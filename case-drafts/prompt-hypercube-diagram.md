# Image-prompt для GPT: «взрыв-схема» рендер-пайплайна гиперкуба

> Как пользоваться: дай GPT **на вход скриншот сцены** (золотая стеклянная фигура на тёмном фоне с бирюзовой авророй) и вставь промпт ниже. GPT нарисует exploded-схему пайплайна, сохранив визуальный язык скрина.
>
> Все подписи уже прописаны точно — GPT должен нарисовать ровно их, ничего не выдумывая. Технические имена (TubeGeometry, UnrealBloomPass, ACES Filmic, SDF, GPGPU) оставь латиницей как есть — это названия, их не переводят.

---

## ПРОМПТ (копируй целиком)

Нарисуй **инфографику-схему рендер-пайплайна** в виде «взрыв-схемы»: стопка из пяти полупрозрачных слоёв-плашек, разнесённых по глубине под лёгким изометрическим наклоном (как разложенные веером карты), сверху вниз — в порядке отрисовки за один кадр. Снизу под стрелкой — финальный кадр.

Опирайся на приложенный скриншот: тёмный космический фон, золотая стеклянная фигура со светящейся сеткой, бирюзовая аврора у нижнего края. Сохрани этот визуальный язык.

**Стиль:**
- Фон — чёрный, почти космос (#0a0a0a), едва заметная бирюзовая аврора снизу.
- Акцент — кислотно-лаймовый зелёный (#A6FF00): номера, рамки активных слоёв, стрелка.
- Текст — белый, пояснения — серые. Шрифт моноширинный, заголовки капсом. Текст идеально чёткий и читаемый.
- Тонкие линии, много воздуха, минимализм и брутализм. Без скевоморфизма, без лишних теней и градиентов. Плашки — тонкая рамка + лёгкая прозрачная заливка.
- Формат 16:9, горизонтальный.

**Заголовок вверху слева:**
РЕНДЕР-ПАЙПЛАЙН · ЗА ОДИН КАДР

**Пять слоёв стопки (каждый: крупный лаймовый номер слева, НАЗВАНИЕ капсом, серая строка-пояснение справа). Подписи строго такие:**

01 — АВРОРА-ЛЕНТЫ
Шесть лент TubeGeometry, вершины колышет трёхчастотный симплекс-шум

02 — GPGPU-ЧАСТИЦЫ
Позиции и скорости частиц считаются на видеокарте каждый кадр

03 — SDF-РЕЙТРЕЙС · ГЕРОЙ
Стеклянная фигура без меша: луч идёт сквозь поле расстояний, Френель и преломление света

04 — BLOOM
Пятиуровневое свечение по ярким пикселям (UnrealBloomPass)

05 — ВЫВОД
Финальный тон-маппинг ACES Filmic

**Между стопкой и низом — вертикальная лаймовая стрелка вниз с подписью:** КОМПОЗИТИНГ

**Внизу — финальная плашка (крупнее, с золотой фигурой со скрина внутри):**
ФИНАЛЬНЫЙ КАДР
один полноэкранный canvas

Все надписи — на русском (кроме технических названий латиницей). Текст должен быть написан без ошибок и без «псевдобукв».
